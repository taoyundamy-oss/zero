## S1 子片及边界

1. S1a：通知出口同轮重放。先用真实 Android 通知管理器验证当前重复提交，再用提醒 ID＋原触发时刻定义轮次，避免时间ID产生多条可见通知；只承诺仍在通知栏的同轮更新，不承诺用户清除通知后绝不再次提醒。
2. S1b：通知失败与提交失败。分别验证未授权、渠道禁用、系统提交异常、条件删除/周期推进失败；失败不得伪装成已交付。取消竞争须经共同 Mutex/条件提交，不越过 owner。
3. S1c：真实中断与剩余设备门。补必要通知后中断、取消及真实窗口送达；不将出口重放夹具称为真实 SIGKILL。纯 JobScheduler 拉起与系统 LMK若无可独立归因证据，只记录未测，不能替代已有必需冷恢复门。
4. 核对既有后台父项，列出尚缺的必验项和已有证据映射，完成后进入 S2；不继续以无限子编号反复扩展范围。
