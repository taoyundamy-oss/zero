### 语料 1：`knowledge/示例专业习笔记.md`

```markdown
# 示例专业习笔记

> - 2026-09-14 / 学习 / 自整理

## 方剂

### 补中益气汤
出自李东垣《脾胃论》。组成：黄芪、人参（党参代）、白术、陈皮、升麻、柴胡、当归、炙甘草。
主治脾胃气虚与气虚下陷之证：食少便溏、四肢乏力、少气懒言，或脱肛、子宫下垂、久泻。
配伍要点：黄芪为君，补中益气升阳；升麻、柴胡助升提下陷之清阳。

### 四君子汤
基础补气方：人参、白术、茯苓、炙甘草。主治脾胃气虚、语声低微、食少便溏。
后世衍化：异功散（加陈皮）、六君子汤（加半夏、陈皮）。

## 穴位

### 足三里
定位：犊鼻下三寸，胫骨前缘外一横指。足阳明胃经合穴。
"肚腹三里留"——消化系统病证第一保健穴：胃痛腹胀、虚劳羸瘦。日常保健灸法常用。

### 三阴交
定位：内踝尖上三寸，胫骨内侧缘后方。足三阴经（脾、肝、肾）交会穴。
主治：月经不调、带下、失眠、脾胃虚弱。孕妇禁针。

### 合谷
定位：手背第一、二掌骨间。手阳明大肠经原穴。
主治头面诸疾——"面口合谷收"：牙痛、头痛、感冒。孕妇禁针。
```

### 语料 2：`knowledge/Zero架构笔记.md`

```markdown
# Zero 架构笔记

> - 2026-09-14 / 工作 / 项目自用

## 核心模块

### FunctionRegistryModule
全部 FC（函数调用）的唯一注册表：注册、分发、权限校验只经此处，模块不得另立并行注册表（破坏禁区）。
UI 程序化调用与 LLM 工具调用同一寻址空间。

### SystemBus
跨层事件总线：onMusicDue（定时播放 tick）、onVoiceActive（语音会话状态，音乐让位）、
onFilesChanged（文件变更，知识库实时索引）。services 层不能注入 app 层组件，一律经总线解耦。

## 关键决策

### MD14 闹钟 tick 语义
音乐定时只用单一 REQUEST_MUSIC=4003：闹钟是唤醒 tick，不是"每个调度一个身份"。
到点做全量到期扫描 + active→firing 原子认领，执行后重排下一最早。
多调度并存靠认领状态机区分，不靠闹钟身份。

### D19 单一心跳
AgentRuntime.onTick 是唯一心跳信号，Scheduler 订阅它分发各 AgentJob；
不得另立第二 tick 源（定时器/循环唤醒一律不加）。

### 记忆与知识库的边界
记忆 = 用户说过的事（一句话一事，会衰减归档）；知识库 = knowledge/ 目录沉淀的文档
（篇章级，永不衰减）。两表分立，共享向量化底座。
```

## 三、跑法（L3 · 5 步）

1. 三篇语料经 `save_to_file(file_name="knowledge/<篇名>.md", format="md", append=false)` 原样写入（或文件管理器直放后等周期路）。
2. `kb_status` 确认：3 文档、块数合理（语料按 300–600 字/块切分，预计 10–16 块）。
3. `kb_reindex` 归零基线 → 逐问 `kb_search(query, top_k=10)`，按 §二判定表记录 Top-5 / Top-10 是否命中。
4. 计算：Recall@K = 命中题数 / 20；术语类、语义类分列（各 10 题）。
5. 记入 §四 记录表新行（轮次/日期/变更说明）。

**纪律**：更换语料版本后历史行作废重跑，不可混表；P1/P2 两轮除被测变量外其余条件保持一致（同语料/同 top_k）。

| 观测 | 结论 |
