## 1. 范围与不可破坏的约束

Zero 是围绕模型的持久客户端系统，职责分为上下文、记忆、工具、模型、执行与观测。沿用现有 Hilt、Bus、ModuleLifecycleManager.safeCall、Room 事务/Mutex、MessagePipeline 3秒和 IMessageFilter 100ms约束，不建设第二套 Agent 执行器。

前序设计：[缓存可靠性·基建修订·ChatGPT接入](【收敛开发设计】缓存可靠性·基建修订·ChatGPT接入.md)。架构入口：ARCHITECTURE_FINAL.md；实施事实以当前源码及最新证据为准，历史设计示例不是当前行为。

- 稳定前缀、原生推理/签名、完整工具配对、按需原文读取、当前换代预算与估算不得退化。不得填充无用前缀刷命中。
- 98%为已定义场景目标；冷启动、失败/取消、unknown、长间隔、换代全部保留。按连接/模型分别报告，不能把单个热窗口当长期通过。
- 不自动切换主力模型、改价格/凭据、清理观测账本或卸载主应用。旧工作树变更原样保留。
- 旧 A9 热资源测试仍暂停。新本地向量资源验收须提前告知且独立有界，不自动恢复旧压力测试。
- 后台抽取/整理必须可取消、有预算、有持久任务状态；模型输出只是候选，来源与权限校验由客户端执行。

## 3. 目标行为

### 3.1 工具与缓存
核心集合以记忆/知识库/技能入口及音乐、日历、闹钟常用操作为候选，按真实注册名称、启用状态、schema体积裁定，不把模块全部工具常驻。工具定义排序确定、版本可追踪，安全判断仍在执行时发生。
工具快照按会话/世代绑定；常用工具从成功执行历史选取，数量和字节双预算，用户固定优先。过期影响下一世代，不逐轮增删前部。非核心保持分类发现和分页，描述含用途/参数例子/不可用原因。原生延迟加载只能在已验证契约启用，通用invoke路径继续可用。

### 3.2 记忆
类型与保留层级/压缩等级/可信度正交：事件、事实、偏好、规范为主要用户分类，保留旧关系/任务/技能/洞察。事实与偏好分别记录用户明示或模型推断；规范必须有用户明确来源，模型总结不能升级权限或覆盖规范。
增量元数据：记录/发生/有效时间、source消息/引用、确认状态、适用范围、supersedes/version、变更理由。旧数据未知字段保留未知，不补造日期或来源。数据库迁移要保留所有旧记忆和usage表。
流水线：来源持久队列→候选抽取→来源校验→分类/冲突候选→事务提交→索引候选→验证发布。模型不得在数据库锁内进行网络调用。更正优先于推断；时态变化保留历史；无法确定的冲突保留双方并显示状态。摘要保留原文引用，防摘要循环自证。用户忘记操作须阻止队列/索引重新引入。
上下文：固定规则/角色/工具→重要记忆世代快照→追加对话/证据/更正；只在自然换代重新合并。即时更正尾部生效；删除敏感记忆优先移除，必要时换代，不以缓存为由继续发送。预算不足时保留规范和可检索引用，不截断成歧义陈述。

### 3.3 角色与链接
角色显示：初识/熟络/亲近/深契；平静/温和/关切/欢快；当前状态、原因、时间、默认冷却及TTL说明；交互次数不是升级进度。负面不升阶、不惩罚降阶；引用和第三方对象不冒充关系信号。动态表达不改变权限/事实规则。
链接支持Markdown标题和裸网址，处理配对括号/中文句末标点，不把代码里的字符串当链接。沿用允许scheme及Android打开路径；失败可见、选择复制保持。网页内容不自动执行；渲染修订不改变保存/发送给模型的正文。

### 3.4 技能
Markdown为正文权威，知识库索引可重建。文档包含用途、触发条件、前提、工具、步骤、成功判据、失败恢复、来源任务、时间、版本、验证状态。专用工具搜索/读取/创建/修改/删除；写入限制在技能根目录，原子替换、版本冲突检测和历史回滚。删除撤出检索；单次成功先为候选经验，验证后可提升。正文按需加载，技能不新增执行权限。

### 3.5 模型与本地向量
模型能力矩阵必须区分：DeepSeek基线；OpenAI API与ChatGPT套餐；智谱；DashScope；Gemini原生/兼容；CF网关/Workers/BYOK；llama.cpp/LM Studio/Ollama/vLLM。字段、原生状态、usage/错误、上下文预算、缓存计量分别由契约承担，不盲传通用参数。未支持能力明确拒绝，不静默剥离。CF完整响应缓存与上游输入缓存分开；本地KV复用不得伪报云cached tokens。
本地向量首选候选BGE-small-zh-v1.5+ONNX Runtime Android；Qwen3-Embedding-0.6B作为质量/多语言对照。候选不是已验证默认。权重/分词器/模板/池化/维度/量化共同定义space；重新建立候选索引，验收后切换；不同space不直接比较。查询优先、索引分批可恢复；不可用退词法，在线回退显式开启。模型不随APK盲目打包，先核查许可、完整性、磁盘和内存预算。
