## 2. 页面基座（A7）

| 部件 | 落地规则 | 验证 |
|---|---|---|
| 页头 | 共用 ZeroPageHeader；一个主标题；二级页返回沿用原路由 | 默认与200%字，返回48dp |
| 分组 | ZeroNavigationGroup：单层圆角、无描边、无阴影；组内轻分隔 | 设置三组、资料/工作区复用 |
| 导航行 | 统一线性图标24dp；正文16sp；辅助文字14sp；最小72dp，可随字体增长 | 点击语义、长描述不截断、所有入口保留 |
| 色彩 | 继续使用原主题令牌；容器与前景显式成对；中性底色、少量强调 | 浅/深/实际系统动态色，正文至少4.5:1 |
| 状态 | 文字明确表达状态；状态点用主题语义色；不单靠颜色 | unknown/stale/失败仍可辨认 |
| 轨迹 | 摘要与正文用onSurface/onSurfaceVariant；错误可用error，不用outline作正文 | 强制白色父级内容色时仍清楚；浅深/大字 |

配置 owner 和持久化 key 不因视觉重构迁移。设置仍有偏好、行为与能力、系统与数据三组；资料、动态模块及运行记录仍在各自主入口。上下文链接复用既有目的路由，后续表单/IM归属清理仍在 A8c。

## 3. Live 方案（A9 顺序实施）

- 保留 Zero 零环身份；球体用程序绘制的柔白—冰蓝—天蓝渐变，不复制品牌图形。蓝白仅用于图形光层，状态文字仍用主题语义色；深色降低光层亮度。字幕容器和控制区共享主题。
- LISTENING 用轻微呼吸；真实能量数据可用时叠加输入反馈，没有数据时不伪造音量。THINKING 用慢速色层位移；SPEAKING 用真实输出活动反馈；INTERRUPTED/IDLE 静态。颜色只辅助，始终显示状态文字。
- 现有服务/会话/麦克风/屏幕共享能力是唯一业务来源；不给未经实现的视频入口或状态增加按钮。结束会话、停止说话等操作立即生效，不等待动画。
- 沿用 ZeroMotion：状态180ms、布局320ms、循环起点1800ms；可见且活动才循环，后台/不可见/减少动态停循环。不得逐 token 动画，不把“正在听”动画冒充麦克风已授权。
- 48dp操作目标、TalkBack名称、减少动态、分屏和200%字必须验收；录像和帧指标属于 A9，截图不替代。
