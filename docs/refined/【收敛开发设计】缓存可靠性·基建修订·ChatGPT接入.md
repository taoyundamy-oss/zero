## 1. 目标与执行原则

先解决缓存P0及长任务可靠性，再修复审查发现的基建风险，最后引入独立ChatGPT账号接入模块。保持现有模型路由、工具执行体系和个人资料。

- **少干预模型，多修基础设施**：保留模型自主选择工具、步骤和资料的能力；不新增统一工具轮数上限、不降低推理能力、不叠加生硬提示词。
- **内容可完整取得**：大结果仅在必要时采用按需展开、分页或原文引用；保留关键字段和错误。小结果原样保留，不统一截短到固定字符数。
- **必要保护保留**：真实上下文上限、取消、身份鉴别、凭据保护、任务认领和防重复副作用属于稳定基建；不扩展成逐次工具审批或命令白名单。
- **渐进实施**：一次一个切片，先复现，再最小修订、测试、编译及必要实机验收；保留现有工作树和失败证据。
- **环境约定**：保留手机当前CF GPT选择；开发默认离线/本地Qwen，云端推理提前告知。热资源测试暂停，长期项由用户日常观察，不新增云端自检。
- **高缓存命中贯穿后续开发（P0设计优先级）**：涉及提示词、工具清单、历史重载、摘要、媒体、换代和模型路由的变更，检查是否破坏稳定前缀与世代内追加关系，并以相关回归验证。只在有实际上下文需求时换代，不为局部便利反复改写旧请求内容；不以冻结必要事实更正或限制模型自主能力换取命中。96–98%作为已定义场景的目标，完整自然样本另报，不承诺每条请求达到该值。
- **预算与效率共同约束**：同时看总输入、未命中输入、输出、额外轮次、任务质量及实际费用；不填充前缀、不保温刷分、不筛掉冷请求或失败样本。测试先复用有效证据及离线/本地模型；主动云调用提前告知范围与预算，累计记账，不把unknown费用记零，不自行扩大既有预算。新APK安装提前告知，避免无必要安装/重启干扰日常观察。用户日常CF GPT选择保持不变。

## 3. 缓存与长任务修订设计

**R4：估算及换代。** 按provider/model/协议区分传输大小与上下文占用；用真实usage校准已发送部分，加上新增输入及输出预留。缺usage或模型切换时使用明确保守回退。校准不得跨账号/模型误复用；用户已有预算不静默覆盖。维持世代内追加稳定，减少不必要换代，同时完成F4的最终请求检查。

**R5：新增输入体积。** 先定位重复、大工具输出与必要原生状态各自占比；仅对明确膨胀点提供可展开内容。保留原始结果和工具配对，模型可按需要取全文；不把删除推理状态当优化。比较输入总量、额外工具往返、延迟和任务完成质量，收益不足则收回改动。

**R6：历史变化定位。** 记录首个差异位置、消息标识摘要、字段类别及来源；覆盖加载、摘要更新、编辑与恢复。日志不含正文、密钥或原生密文；正常令牌续期不改变提示词或历史。

**R7：真实复验。** 固定场景与完整样本，分别记录冷启动、连续追加、长工具、换代及跨进程恢复。全样本统计不能筛掉低命中、失败或unknown；对比实际任务成功、总输入与费用。原固定热组98%门与真实混合组分列；保留96–98%目标，不保证每个冷请求达到98%，不填充前缀刷分。未达目标就保持未通过并解释差额，不能以局部热组替代。

## 4. Sign in with ChatGPT独立模块设计

### 4.1 可行性与范围

2026-10-12官方文档核查显示，符合条件的客户端可通过ChatGPT账号授权使用套餐推理。Zero的开源/发布资格、具体账号权限及Android回调仍待验证。身份登录不等于获得套餐推理权限，也不提供ChatGPT历史对话。

建议采用**独立认证模块＋ILanguageModel适配**；保留现有ModelSelector的能力、enabled、priority和上下文选择逻辑，不引入第二套Agent执行器。它是新增连接来源，不替换当前CF GPT、本地Qwen或其他既有模型。

### 4.2 模块边界

| 组件（拟新增） | 负责 | 与现有体系衔接 |
|---|---|---|
| ChatGptAuth模块 | 系统浏览器登录、回调、账号/注册状态、刷新、退出、受保护凭据 | Hilt注入小接口，业务层仅用身份和凭据句柄；设置入口放在现有模型管理 |
| ChatGptPlanLanguageModel | 本账号模型能力与请求，冻结本回合账号/模型身份 | 实现ILanguageModel，注册ModelSelector，用户主动设置启用/优先级 |
| 套餐Responses契约 | 官方端点、参数、函数工具编码及流终态 | 复用可兼容的流解析、工具执行、usage和历史基础设施；差异限定于该连接 |

关键边界：

- 浏览器Authorization Code + PKCE，校验state/nonce及ID token；当前开源流程用127.0.0.1回环回调，Android监听存活、浏览器返回、取消和进程恢复需实测。
- 独立保护账号凭据；同身份并发刷新合并、轮换原子保存，退出/切号后的迟到刷新不能恢复旧账号。F6先完成，刷新令牌不进入普通备份或日志。
- 账号/注册/连接/模型隔离原生状态；同账号刷新凭据不改变稳定前缀。授权凭据仅用于官方端点，不能转发到CF、自定义baseUrl或跨域重定向。
- 套餐接口要求store=false、stream=true；system项、max_output_tokens及函数工具编码存在差异，不能直接把OAuth令牌塞进CF配置。同步调用可聚合SSE；其他路由参数保持原语义。
- 当前该流程不提供音视频输入和转写API；继续按现有媒体能力路由。文本/图片等能力按实际模型和协议核验，不根据模型名字猜测。
- 套餐使用量与API费用分列。未授权、额度不足、退出均明确显示，不偷偷改走付费API；模型目录成功不等同推理权限已验收。
